## 判断的起点

一项能力从「稀缺」变成「供给充足」时，利润一定会从能力本身转移到别处。
模型能力正在快速趋同，所以问题不是「智能体能不能赚钱」，
而是**当推理能力不再稀缺时，价值会沉淀在哪一层**。

## 三个可能沉淀的位置

```
┌──────────────┬──────────────────────────────┐
│ 私有上下文    │ 别人拿不到的历史与业务事实     │
├──────────────┼──────────────────────────────┤
│ 分发渠道      │ 用户已经在哪儿、切换成本有多高  │
├──────────────┼──────────────────────────────┤
│ 交付与责任    │ 谁为结果负责、谁承担合规成本    │
└──────────────┴──────────────────────────────┘
```

## 推演

- 单纯「调用模型 + 拼提示词」的产品会被压到接近成本价，因为供给端没有门槛；
- 掌握**私有上下文**的产品可以持续变强——它积累了别人复制不了的数据；
- 掌握**分发渠道**的产品可以把同等能力卖出溢价，因为用户迁移的成本由用户自己承担；
- 愿意**为结果负责**的产品可以把价格锚定在风险而非算力上。

## 需要观察的信号

1. 模型调用价格是否继续以高于摩尔定律的速度下降；
2. 头部产品是否开始把差异化写进「数据积累」而不是「效果更好」；
3. 是否出现为「结果」而非「调用次数」付费的定价模型。
