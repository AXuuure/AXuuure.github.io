## 先分清两个词

模型自己并不「记得」任何事。它的全部输入就是这一次请求里塞进上下文窗口的文本。
所谓记忆，是**系统在窗口之外替它保管内容，并在需要时把相关内容放回窗口**。

```
用户提问
   │
   ▼
┌──────────────────────┐
│   上下文窗口（临时）   │◀── 检索命中的记忆片段
└──────────────────────┘
   │ 写入新事实
   ▼
┌──────────────────────┐
│   长期记忆存储（持久） │
└──────────────────────┘
```

## 长期记忆解决的是什么问题

- **跨会话延续**：这次对话里确认的偏好，下次不必重新交代；
- **容量上限**：上下文窗口再大也有边界，长历史必须被压缩或外置；
- **一致性**：同一事实在多轮、多会话里应当给出同一个答案。

## 与检索增强的关系

检索增强负责「从语料里找相关材料」，长期记忆负责「记住与我有关的结论」。
两者共用检索这一手段，但数据的来源与生命周期完全不同：前者是外部知识，后者是交互沉淀。
